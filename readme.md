# The Race (Cars)

A browser-based project showcasing JavaScript constructor functions, prototypal inheritance, DOM manipulation, and event handling. The theme has been tailored to **cars** (Audi, Mustang, Viper, Pickup). Users can add cars, line them up, start a race, and see a winner announced. Bonus interactions include hover zoom and right‑click delete.

---

## Installation

Follow these steps to set up the project locally:

1. **Clone the repository** (or download the ZIP):
   ```bash
   git clone https://github.com/andreragbir121/web-racer.git
   cd web-racer
   ```
2. **Project structure** (key files):
   ```
   .
   ├─ index.html
   ├─ main.css
   └─ src/
      ├─ car.js
      ├─ audi.js
      ├─ mustang.js
      ├─ viper.js
      ├─ pickup.js
      └─ init.js
   ```

3. **No build step required**. Open `https://andreragbir121.github.io/web-racer/` in your browser.

---

## Usage

1. **Open** `index.html` in your browser.  
2. Use the **Add Car** buttons to create instances (Audi, Mustang, Viper, Pickup).  
3. Click **Get Ready for Race** to align cars on the **left** and display the **finish line**.  
4. Click **START** to begin the race. Cars move toward the finish; the first to cross is declared the **winner**.  
5. **Bonus interactions**:  
   - Hover over a car to see type/speed (and zoom if enabled in CSS).  
   - **Right‑click** a car to delete it from the race.

> Tip: If you want to reset after a winner alert, press **Get Ready for Race** again.
